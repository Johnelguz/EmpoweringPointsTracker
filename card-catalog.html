Shared Card Catalog

The tracker reads card options and benefit defaults from the published Google Sheet.

Sheet layout

Use one row per benefit. Repeat the card name, annual fee, multipliers, points label, and image URL on each benefit row. The points label is shown beside the user's numeric points balance (for example, "Ultimate Rewards points"). For the image, use a public HTTPS image URL from the card issuer's website; the issuer must allow the image to be displayed on other sites. A card with no benefits can have one row with the benefit columns blank.

Keep the column headers exactly as shown. Points Label is optional; if omitted or blank, the tracker uses "Points." Annual fees and benefit values should be non-negative numbers; currency symbols and commas are also accepted. Publish the sheet tab as CSV so all visitors see the same catalog. If an image is unavailable or cannot be embedded, the tracker displays card initials instead.

Manage the catalog

Edit the source Google Sheet, then publish the updated tab as CSV. The tracker reads the published sheet directly; this guide does not edit it. Since the sheet is published, its contents are publicly readable.
